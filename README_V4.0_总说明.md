# 小小AI科学家 V4.0｜DeepSeek真实AI系统

本版本在V3.0课程资源基础上新增可运行的Node.js后端、DeepSeek服务端调用、学生AI导师、教师AI评价工作台、在线/离线状态标识和安全部署指南。

**首次使用必须先阅读：** `部署与配置/README_V4.0_从零部署.md`

## 快速开始
1. 安装Node.js 20+
2. 复制 `.env.example` 为 `.env`
3. 申请并配置DeepSeek API Key、教师密码和TOKEN_SECRET
4. `npm install`
5. `npm start`
6. 浏览器访问 `http://localhost:3000`

未配置API Key时会进入离线演示模式；不能将其作为真实AI功能的证据。
