# 小小AI科学家｜V3.0正式参赛优化包（离线交互版）

## 一、作品交付
- `在线课程/index.html`：统一版课程网站，离线可打开。
- `课程方案/`：作品总览、课程设计、答辩提纲、课程标准映射与成果证据矩阵。
- `教学实施/`：教师实施手册。
- `学生资源/`：学生探究任务单。
- `评价与试用/`：评价与试用方案、测评A/B卷、试用数据空表。
- `AI技术与治理/`：系统架构、儿童隐私风险控制、AI协同设计披露与提示词。
- `参考资料/`：政策、课程标准与AI素养框架参考资料。
- `架构图/`：课程总体架构图与Mermaid源文件。
- `提交前检查/`：正式参赛提交验收清单。

## 二、打开方式
解压后双击 `在线课程/index.html`，建议使用Chrome、Edge或Firefox。无需账号、无需网络、无需安装依赖。推荐先从首页开始，再按评审路线体验。

## 三、评审体验路线（约8—10分钟）
1. 首页：课程定位、学习目标与五单元学习地图。
2. 五大单元：打开单元02，查看目标、知识、活动、流程、产出和评价证据。
3. 探究实验室：改变水果特征，观察规则模拟输出并填写实验记录。
4. 学习助手：选择“AI会犯错吗”等主题体验离线预设学习支架。
5. 学习评价：完成5道题并阅读解析。
6. 创意设计卡：生成、导出文本或打印PDF。
7. 教师与评审：查看课程标准映射、AI状态披露与实施路线。

## 四、技术真实性声明（请评审前保留）
当前网页是离线交互教学原型。水果分类为人工编写规则模拟；学习助手为人工编写/审核的预设反馈；测评为固定题库和规则评分。网页没有实时大模型API调用，没有训练真实机器学习模型，也不上传学生输入。课程设计与资源开发阶段使用生成式AI辅助目标对齐、差异化提示草拟、反馈结构和评价题目初稿，相关任务、提示词和人工审校要求见 `AI技术与治理/12_AI协同设计记录与提示词.md`。设计阶段AI辅助不等于学生端实时AI服务。

## 五、提交前必须完成
- 真实课堂/研学试用后填写试用表；未试用不得编造数据。
- 核验课程标准原文、政策适用性、参考资料链接及引用格式。
- 按主办方模板补充团队/单位信息、申报表、封面、指定页数和授权材料。
- 若赛事要求学生端真实AI调用，须另行完成服务端部署、适用年龄与隐私审查、安全测试及现场验证；不要把API密钥放入前端。
- 逐项完成 `提交前检查/14_正式参赛提交验收清单.md`。
